# Keymaker — UAT Report: UI/UX Issues & Enhancements

**Date:** 2026-08-14 · **Method:** 5 parallel UAT agents driving the production build in headless Chromium (Playwright 1.56.1), ~150 automated checks plus manual inspection · **Scopes:** core encrypt/decrypt flows · error handling/adversarial input · tools tab (seed/SeedQR/dice/generator) · accessibility/responsive · PWA/offline/performance/first-time UX

---

## ★ Headline: The Core Promise Holds

**Zero-network claim VERIFIED:** with 100% of network requests aborted at the browser level, a full Argon2id text encrypt→decrypt round-trip completed — **0 network requests attempted**. Service worker controls the page on first load; offline reload works; CSP in served HTML has hashed scripts, no `unsafe-inline`, `connect-src 'none'`; DOM-injected inline script blocked; memory flat across 10 encrypt/decrypt cycles (no leaks); zero console errors.

## Verified Working — No Action Needed

- **Byte-exact round-trips**: text (incl. emoji), 62B file, 5MB binary, 10MB file (692ms encrypt), CJK/emoji filenames; container overhead +75B on 5MB.
- **All 6 KDF×cipher combos** with accurate Inspect readouts; custom slider params correctly reflected.
- **Wrong password / wrong key file / missing key file** → identical generic error, no oracle, no partial output.
- **Unicode passwords**: NFC-encrypted decrypts with NFD input (normalization works); emoji passwords fine.
- **Seed detection**: 15/15 checks — all 5 valid lengths, checksum failure, normalization, 300ms debounce.
- **SeedQR**: gated reveal (QR not in DOM until revealed), downloaded PNG decodes to exact Standard SeedQR digits, invalid seed → no SeedQR option.
- **Dice math**: 26/26 independently verified (d6=2.58 bits/roll, 99 rolls=255.9 bits, impossible faces rejected, multi-digit d20 faces handled).
- **Password generator**: 32 chars/91-char set, "≈208 bits" claim matches ⌊32·log2(91)⌋ exactly, rejection sampling, round-trips.
- **Clipboard**: copies byte-exact; 60 s auto-clear verified against the real timer.
- **0-byte file / >100MB file**: clean graceful errors. Rapid clicking, hammered Generate, rapid mode switches: stable.
- **Offline/PWA**: SW activates on first load, offline reload OK, manifest+icons valid, all lazy crypto chunks precached.
- **Performance**: FCP 256ms; flat 93MB heap across 10 cycles — no leaks.
- **Dialogs**: QR modal has proper aria labelling, clean 2-stop focus trap, Escape closes and restores focus. Toasts announced via live region (assertive for errors).
- **Contrast (dark theme)**: all measured pairs pass WCAG AA. Zoom 200% fully usable. 390/768/1920 viewports clean.

## First-Time User Journey (narrative)

Landing is immediately legible and the task is obvious within seconds. Progressive disclosure is done right — Advanced translates jargon into plain language ("Memory-hard — resists GPU/ASIC password cracking"). Decrypt self-describes the container before decrypting; output is blurred by default. Microcopy quality is high. Friction points: silent disabled-button state (U15), footer GitHub ambiguity (U16), multi-second total freeze at high KDF settings with no feedback (U1 — a first-time user may think the page crashed), and losing an in-flight operation by clicking away mid-KDF with no warning (U3).
