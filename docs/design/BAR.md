# Keymaker workspace — Linear reference, Graphite palette

Approved direction, 7 September 2026: Linear's component precision with the
Keymaker mock layouts. This supersedes the earlier ElevenLabs marketing-page
layout. Reference: [Linear on Refero](https://styles.refero.design/style/90ce5883-bb24-4466-93f7-801cd617b0d1).

## Review criteria

- Compact, persistent navigation. Encrypt, Decrypt, Recovery, Audio and Tools
  have distinct destinations. Workspace offers task entry points, not analytics.
- One controlled form, divided into Content and Protection. No duplicate secret
  fields at responsive breakpoints, no unnecessary Next-button wizard.
- Container preview remains alongside the form on desktop and below on mobile.
  Its blue/ember diagram describes actual header dimensions, not random bytes.
- Neutral Graphite grounds and the approved Spline Sans / JetBrains Mono
  typography remain. The user rejected the brown/taupe grounds in the first
  implementation preview. Linear supplies control styling, not a copied brand.
- Flat grounds, crisp hairlines, 8px controls, 12px panels. No glass, glows,
  gradients, pill-shaped primary buttons or marketing hero in the workbench.
- Page titles 28–32px, weight 400; section titles 15px/500; body 13–14px;
  captions/data at least 12px. Whitespace separates tasks, not decorative cards.
- Typography accents: off-white page titles, ice-blue panel titles, action-blue
  prompts and controls, cyan selected options and navigation, mint validation.
  Descriptions stay silver; entered content stays off-white. No color-only states.
- Visible focus, readable contrast, reduced motion and touch targets take
  precedence over reference density.
- Preview is a plan. Container details are parsed metadata. Neither is proof
  of successful decryption. Verification never exposes plaintext.
- Recovery distinguishes configured shares from issued shares, a download request
  from a saved copy, and test instructions from a passed test. No invented history,
  cloud vault, identity, device-trust badge or security score.

Changes remain presentation-focused. Crypto, formats, workers, offline recovery,
secret clearing, cancellation, and existing advanced options remain intact.
