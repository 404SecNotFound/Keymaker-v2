# Pinned toolchain for the recovery-dependency audit.
#
# Separate from requirements.txt on purpose. That file is the recovery
# oracle's runtime — two libraries, meant to be installable on a machine
# nobody can predict, years from now. This one is CI-only tooling and can
# afford to be rigid.
#
# Why hashes, when requirements.txt has none
#
#   The audit step used to run `pip install pip-audit`, unpinned, inside the
#   pipeline whose job is verifying supply-chain properties. Whatever PyPI
#   served that morning ran with full access to the checkout. That is the
#   exact shape of the problem the rest of this repo spends effort avoiding:
#   npm is lockfiled, GitHub Actions are SHA-pinned, and this was neither.
#
#   Version pins alone would be most of the fix, since PyPI will not let a
#   released file be replaced. Hashes close the remainder — a compromised
#   index or a substituted mirror — and cost nothing to keep once generated.
#
# Regenerating
#
#   Must be done on the same Python minor as the conformance job (3.12), on
#   linux-x86_64, because some of these are compiled wheels and the hashes
#   are per-artifact:
#
#     python3.12 -m venv /tmp/av && /tmp/av/bin/pip install pip-audit
#     /tmp/av/bin/pip freeze | sort > /tmp/pins.txt
#     /tmp/av/bin/pip download -r /tmp/pins.txt -d /tmp/w
#     # then sha256 each file in /tmp/w and write it beside its pin
#
#   Verify before committing:
#
#     python3.12 -m venv /tmp/check
#     /tmp/check/bin/pip install --require-hashes -r reference/audit-requirements.txt
#
# One transitive dependency is deliberately absent: pip itself, which pip-api
# requires with no version constraint. `pip freeze` omits it, every runner
# already has one, and pinning it here would silently downgrade the runner's
# pip as a side effect of installing an audit tool. Verified rather than
# assumed — a bare 3.12 venv carrying pip 24.0 installs this file under
# --require-hashes without reaching for the network for pip.
#
# Generated 2026-08-16 against Python 3.12, linux-x86_64. pip-audit 2.10.1.
